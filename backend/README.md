# Local Browser Agent backend

Express/WebSocket companion for the MV3 extension. Task state, observations, files, model responses, and extracted data exist only in memory and are cleared when tasks end; there is no database.

```powershell
npm install
npm run dev
```

The server binds to `127.0.0.1:3333`. It loads `backend/.env` automatically; externally supplied environment variables take precedence. Add `OPENROUTER_API_KEY` there, then restart the backend. With `LLM_PROVIDER=openrouter`, decisions use `OPENROUTER_MODEL=openrouter/free` by default and fall back to local `qwen2.5:7b` on errors. Without a key, Ollama is used immediately. Set `LLM_PROVIDER=ollama` for local-only decisions. Only `openrouter/free` and explicit `:free` model IDs are accepted.

OpenRouter receives the task and compact page context. API keys stay in the backend and are not exposed by health/settings endpoints. Captured answers stay in temporary task memory and are pasted verbatim through `capture_text` / `paste_text`, rather than regenerated by the model. Captures over 32 KiB fail explicitly.

Check `GET /health` and `GET /api/settings/runtime` for provider configuration and Ollama fallback availability. Reload the unpacked extension at `chrome://extensions` after rebuilding `frontend/dist`; the panel checks its build version against the worker and blocks tasks if they differ.

Agent decisions use Ollama native tool calls with a 300-second total deadline, a 150-second first attempt, and one reduced-prompt retry. The model stays loaded for 10 minutes by default to make later decisions substantially faster.

Redacted JSONL diagnostics are written to `backend/logs/backend.jsonl`, rotated at 5 MiB, and limited to five files. Console verbosity follows `LOG_LEVEL`; file diagnostics retain every level. Page text, screenshots, form values, credentials, cookies, and tokens are not written to diagnostics.
