# Development Environment

## Prerequisites

- Windows is a primary development target.
- Current Chrome and/or Microsoft Edge.
- Node.js LTS.
- npm.
- Ollama installed locally.
- A configured Qwen text/agent model.
- A configured local vision-capable model when screenshot interpretation is required.

## Backend environment

Recommended `.env.example`:

```env
HOST=127.0.0.1
PORT=3333
OLLAMA_BASE_URL=http://127.0.0.1:11434
AGENT_MAX_STEPS=50
AGENT_RECOVERY_LIMIT=3
NAVIGATION_TIMEOUT_MS=30000
ACTION_TIMEOUT_MS=15000
LLM_TIMEOUT_MS=120000
LOG_LEVEL=info
```

Do not put credentials in committed `.env.example`.

## Run backend

```bash
cd backend
npm install
npm run dev
```

## Run frontend

```bash
cd frontend
npm install
npm run dev
```

Vite's extension build/watch strategy may output to `dist/` or another configured directory. The README generated by implementation must state the exact folder to load unpacked.

## Chrome

```text
chrome://extensions
Developer mode -> On
Load unpacked -> frontend build directory
```

## Edge

```text
edge://extensions
Developer mode -> On
Load unpacked -> frontend build directory
```

## Expected health checks

Backend should expose a health endpoint returning at least:

- backend healthy
- Ollama reachable/unreachable
- available model count or discovery status
- transport/WebSocket status

Do not require a database health check.
