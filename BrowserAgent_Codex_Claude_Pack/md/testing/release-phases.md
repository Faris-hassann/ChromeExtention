# Implementation & Release Phases

## Phase 1 — Bootstrap

Create separate frontend/backend apps and dev scripts.

## Phase 2 — Connectivity

Backend health, Ollama health/model discovery, WebSocket, side-panel connection states.

## Phase 3 — Browser observation

Semantic page snapshot, element IDs, screenshot capture, tab/frame state.

## Phase 4 — Tool execution

ExtensionBrowserDriver + core tool registry.

## Phase 5 — Agent

Qwen structured decisions, task state machine, automatic observation barrier.

## Phase 6 — Permissions/security

Site permissions, risk/approval engine, prompt-injection tests.

## Phase 7 — Complex browser workflows

Multi-tab, forms, files, iframe/Shadow DOM, popups.

## Phase 8 — Vision

Vision routing and visual verification.

## Phase 9 — Recovery/completion/workflows

Bounded recovery, final verification, workflow import/export.

## Phase 10 — Test hardening

Deterministic sites, E2E, adversarial tests, full suite.

## Phase 11 — Playwright driver

Ensure Playwright driver obeys the same tool/policy/observation contracts.

## Phase 12 — Native Messaging preparation

Transport interface, registration scripts/documentation; production packaging may follow separately.
